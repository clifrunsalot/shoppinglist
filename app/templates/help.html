Grocery List — User Guide

This guide covers everything you need to manage your personal grocery list. Use the sections below to find answers quickly.

Managing Your List

How do I add an item?

Tap the + Add Item button in the bottom-right corner. A panel slides up with two tabs:

  • New Item — type in any name, quantity, unit, category, and store, then tap + Add to List. Name and store are required.
  • From Defaults — browse or search the curated default list. Tap any row to pre-fill the New Item form with that item's details. Items already on your list show an In list badge; you can still tap them if you want a second entry with a different name.

You can change the pre-filled name before saving — the item will be saved as a brand-new custom entry, not linked to the default template.

How do I mark an item as done?

Tap the ⬜ checkbox on the left side of any item row. It changes to ✅ and the item name gets a strikethrough. Tap it again to mark it pending.

Use the Done filter chip at the top to see only items you've already checked off, including a running price total if prices are set.

How do I edit an item's details?

Tap anywhere on an item row (not the checkbox or delete button) to select it. A Details button appears in the bottom-right corner — tap it to open the detail panel.

The panel has two tabs:

  • Details — edit name, quantity, and unit. Changes save automatically a moment after you stop typing.
  • Advanced — change category, store assignment, and price. These save as soon as you change the selection.
How do I delete an item?

Tap the ✕ button on the right side of any item row. The item is removed immediately. Deletion is permanent — there is no undo.

Deleting all your items will leave the list empty. Refreshing the page will not restore deleted items automatically. Use Import Default Items in Settings if you want to start fresh from the default list.

Filtering & Searching

Category chips (All, Pending, Done)

The scrollable chip bar below the header shows one chip per category that's actually in use on your list, plus built-in All, Pending, and Done chips.

  • All — show every item regardless of status.
  • Pending — show only unchecked items.
  • Done — show only checked items; a price total appears when prices are set.
  • Any named category — show only items in that category.
Filtering by store

The 🛒 store filter button (top-right of the filter bar) opens a popover listing all your stores. Select one to show only items assigned to that store. A tinted pill appears below the filter bar showing the active store. Tap Clear or select All stores to remove the filter.

Text search

Type in the Filter items… text box to instantly narrow the list to items whose name contains your search term. Category and store filters stack with the text search.

Settings

How do I open Settings?

Tap the ⚙ gear icon at the left end of the filter bar. A sheet slides up from the bottom. Tap outside the sheet or tap the close button to dismiss it.

Changing the color theme

In Settings, choose from four themes: Meadow (green), Ocean (blue), Sunset (orange), and Berry (pink). The selection is saved in your browser and restored automatically on your next visit.

Importing the default grocery list

Tap Import Default Items in Settings to pull in the administrator's curated grocery list. The import behaves as follows:

  • Items in the default list that you don't have yet are created on your list.
  • Items you already imported previously (linked to a default template) are reset to the current default values — name, quantity, unit, category, and store.
  • Items you created yourself whose name happens to match a default are linked to that template but your data (quantity, unit, etc.) is preserved.
  • Purely custom items with names that don't match any default are left untouched.

This means running the import multiple times is safe — it won't duplicate items or erase your custom entries.

Changing your password

In Settings, scroll down to Change Password. Enter your current password, then your new password twice (minimum 8 characters), and tap Update Password. Use the Show toggle to reveal characters as you type.

Account

How do I sign out?

Tap Log out in the top-right corner of the header. You will be taken back to the sign-in page. Your list is private and only visible when you are signed in.

Is my list private?

Yes. Each account has its own isolated list. Other users cannot see your items, stores, or prices. Administrators can manage the shared default templates and category/store options, but cannot view or modify your personal list items.

I forgot my password

There is no self-service password reset. Contact your administrator — they can generate a temporary password that you can use to sign in and then change immediately from Settings.
